# Weather-Widget-App

A simple React weather widget with city search, temperature, humidity, and real-time API data from OpenWeather. Styled with Material UI.

## 🌤 Features

- 🔍 City search
- 🌡 Temperature & humidity
- 🔄 Live API data from OpenWeather
- 🎨 Styled with Material UI
